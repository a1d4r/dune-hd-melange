# Changelog

**English version**

## 0.48.0 — 28.10.2026
- **INFO in the player** shows the name of the release under the title and, in the description, a line about the release (video, audio, size, voice-overs) and the description of the movie or series from the Dune card. A series in a season playlist has its title once, the episode as "S01E02".
- **TorrServer window with INFO.** Playing via TorrServer, **INFO** shows, next to the Dune's own INFO window, a TorrServer window at the top right in the same style: the release, the download and upload speeds, peers and seeders, how much is loaded; updated every second. It closes together with INFO. If TorrServer gives no numbers, the window says why: not responding, slow to respond, it does not have the release.
- **Sort of the release list by the colour keys** of the remote: **red** — "Auto", as AIOStreams sent it (the default), **green** — by seeders (in a Debrid list: cached releases first), **yellow** — by size (biggest first), **blue** — by date added (newest first). **Pressing the same key again reverses the order** (fewest seeders, not cached, smallest, oldest first; "Auto" — the AIOStreams order backwards); another key starts with its usual order. Releases with equal values keep the AIOStreams order; those without the value (no seeders, size or date) stay at the end either way. The keys are tabs under the title above the list: the current one bright and underlined, a triangle shows the direction (▼ usual, ▲ reversed); the list shows 12 releases instead of 13. The choice and its direction are remembered for all movies and series, after a restart, "Refresh" and ← / → too; after a change the cursor goes to the first release. With a remote without colour keys there are no tabs.
- Fixed: via TorrServer an episode is now found in releases whose files are named by a number at the start ("01. Title.mkv"). Before, such a release gave "The release has no file for this episode".

## 0.47.0 — 27.10.2026
- **Transmission in "Download to server…".** A server block of the settings page has a new first field, **"Client"**: "qBittorrent / rdt-client" (as before) or "Transmission". For Transmission, "Category" becomes **"Download folder on the server"** and "Tags" become **"Labels"**; both are optional. The address is that of its web UI: `http://host:9091` (the RPC path is added by Melange), one copied from the browser (`…/transmission/web`), `…/transmission` or your own RPC path. **"Check"** logs in and shows "OK: logged in · version 4.1.3", or the reason: wrong login or password, the server does not let the Dune in (add its address to `rpc-whitelist`), Transmission does not accept the server name (use an IP or add the name to `rpc-host-whitelist`; on the Dune too), not Transmission at this address. Transmission 3.x does not keep labels: "Check" says so. On the Dune a release Transmission already has gets **"Already in <server>"**. Servers saved before stay qBittorrent / rdt-client.

## 0.46.2 — 27.10.2026
- "Download to server…": the same release can be sent to the same server again (for example, if you deleted it in the client). Before, Melange remembered what it had sent and said "Already added to <server>" without asking the server. The "already added" mark in the list of servers is gone too. If the client still has the release, qBittorrent does not take it twice: "Not added to <server>" says the client did not accept the torrent; rdt-client keeps the one it has.

## 0.46.1 — 25.10.2026
- Release list: the hint row at the bottom of the screen now also shows the keys **POP UP** (≡, the MENU key) — "Actions" (the menu of the release) and **INFO** (i) — "Details" (the release details). The captions of the hints are a little smaller and the ← → arrows of an episode are as high as the ≡ sign, so everything fits in the row with the counter.
- Release list: the number of releases is only in the counter at the bottom right ("5 / 60"); the title no longer shows "60 releases". An episode keeps "S02E07" at the right of the title.

## 0.46.0 — 25.10.2026
- **"Skip intro" and "Next episode" in episodes.** The player shows "Skip intro" at the start of an episode (ENTER jumps to the end of the intro or the recap) and "Next episode" with a countdown over the credits (at zero the next episode starts). Melange asks the AIOStreams server the releases came from for the times, sending the length of the file when AIOStreams knows it. The buttons appear if the server supports this — the public server of Melange, `aiostreams.kompotik.com`; with other servers episodes play as before. Works on the r25 firmware. Via TorrServer only the episode you start gets the buttons: the other episodes of the same pack, which the player moves on to by itself, play without them.

## 0.45.1 — 24.10.2026

- On the r25 firmware the "Continue" item of "Play…" reads "Continue: Melange" with a capital letter (was "melange"). The caption is updated when this version is installed.

## 0.45.0 — 21.10.2026
- **TorrServer with a login and password.** The "TorrServer" screen of the settings page has **"Login"** and **"Password"** fields under the address (the password is hidden, the eye shows it); they also work with an empty address, for the TorrServe app on the Dune with "Local TorrServer with Authorization" on. The address may be typed as `login:password@host:port`: on saving the login and password go to their fields, and the address is stored without them. A login without a password or a password without a login is an error of the field. **"Check"** now also tells "TorrServer asks for a login and password" and "TorrServer did not accept the login or password"; the password is sent in the request body, not in the address of the page. "Watch via TorrServer" sends them to TorrServer; if they are missing or wrong, "Could not open via TorrServer" says so and points to the Melange settings → TorrServer. The password never goes to the log.
- **"Play" or "Add & Play".** The "TorrServer" screen of the settings page has **"What to do with a release"** under the login and password: **"Play"** (the default, as before: TorrServer forgets the release after watching) or **"Add & Play"** (the release stays in the TorrServer list). It applies to every start via TorrServer: ENTER on a P2P release, MENU → "Watch via TorrServer", Continue Watching, the next episode in the player.
- The MENU item **"Download in an app…"** is now **"Open in an app…"**: it is also the way to add a release to the list of TorrServe, which offers "Play", "Add & Play" and "Add" for a magnet link. "Watch via TorrServer" is different: it opens the Dune player with the playlist of episodes, Continue Watching and the next episode.
- The **"Opening via TorrServer"** window shows what TorrServer is doing in words ("Getting info", "Preloading", "Working"…; "Waiting for the file list" when it does not say), the seconds, on the next line the peers and the connected seeders, then the download speed ("—" while there is none, so the window does not change its height).
- Fixed: on some Dunes Melange did not see the settings saved on the page ("Saved" on the phone, but "not set" in Melange) — the file of the settings got an owner the plugin could not read. Now it gets the owner of the plugin itself. If Melange still does not see the saved settings, open Melange on the Dune (any screen will do, e.g. its settings screen) and save the settings on the page once more. If it still cannot read them, its log says why.

## 0.44.0 — 19.10.2026
- "Torrents" got its own **"Where to look for releases"** on the "Where to get films" screen, apart from the Debrid one: **"Russian trackers only"** (JacRed only, a faster reply) or **"Everywhere"** (Torrentio, JacRed, TorrentsDB, Comet and StremThru Torz: more releases). On `aiostreams.kompotik.com` the server itself searches JacRed, on the other servers it is searched through Magnetio, as before.
- **"Russian trackers only" is now the default for "Torrents"**: a new "Torrents" config gets JacRed only, until you choose another template yourself. Existing "Torrents" configs do not change: the choice shows their template ("Everywhere") until you choose another one, and saving them as they are keeps the default for new configs. As with Debrid, another template and "Save" reset the config after a question; the main screen shows the template: "Torrents · via TorrServer · Russian only".
- "Reset to the template" with "Torrents" names the template ("Everywhere", "Russian trackers only") instead of "Torrents".
- The AIOStreams server has a screen of its own, **"AIOStreams"**: on the main screen its line is right under "Where to get films" and shows the host of the server (the dot is yellow while it has no config of the chosen answer). The servers are cards, as JacRed is ("of Melange" on `aiostreams.kompotik.com`, "no TMDB" on those without their own TMDB), your own one is the last card, **"Own server"**: its address with "Check" appears under it when it is chosen; under them are the TMDB key and the former "Config in AIOStreams" section (login, password, "Reset to the template"). The "Server: … · Change" line on "Where to get films" and the "Config in AIOStreams" line of the main screen are gone; the settings stay as they are.
- The "Voice-overs and tracks" screen is now called **"JacRed"**: JacRed not only suggests voice-overs but also searches for releases. **"Own JacRed"** is the last card of the list, as on the "AIOStreams" screen, not a collapsed block: its address, key and "Check" appear under it when it is chosen. The values stay when you choose another card.
- **"Where to look for releases"** is now cards with an explanation under each template, so they can be compared without opening a list. When the template of the config is not known yet or was changed in AIOStreams, no card is chosen and a line above them says so.
- The TorrServer address is always in the **"TorrServer"** section; with "Torrents" the "Where to get films" screen has a link to it under "Where to look for releases".
- If you go back to 0.43.x, a "Russian trackers only" config keeps working; "Reset to the template" there makes it "Everywhere".

## 0.43.2 — 17.10.2026

## 0.43.1 — 16.10.2026

A track title no longer repeats the codec and channels: "RU · DD 5.1 · DD 5.1 - Dub Pythagor" is now "RU · DD 5.1 · Dub Pythagor".

## 0.43.0 — 16.10.2026
- New settings page. The main screen shows whether everything is set to watch (or what is left to do) and the list of sections, each with its current value and a status dot; a section opens as its own screen ("‹ Settings" or the phone's Back goes back). The first choice is one question with three answers, **"Where to get films"**: Debrid, "Torrents" or your own AIOStreams config; on the first run the main screen asks it right away. With both Debrid keys empty there is a Real-Debrid / TorBox switch and one field, the second key is added by a link. With "Torrents" the TorrServer field is on the same screen. "Check" is a small button inside the field, the result is a line under it. **"Compare speed"** of JacRed writes the reply time and the number of releases into the line of each JacRed. One **"Save"** button for the whole page, at the bottom of any screen, appears only when something is changed and shows the number of changes; when saving fails, the section of the field opens and the field is highlighted. The page follows the phone's light or dark theme. The config template is now **"Where to look for releases"**: "Everywhere" (was "JacRed + addons") or "Russian trackers only" (was "JacRed only"). Without JavaScript the sections open by links, and saving works as before.
- Without Debrid: the answer **"Torrents"** in "Where to get films" on the settings page (next to Debrid, as before, and your own config). No key is needed: releases are found by Torrentio, JacRed, TorrentsDB, Comet and StremThru Torz and play via TorrServer on the Dune; releases are sorted by seeders (0–2, 3–9, 10–29, 30 and more), and a heavy release (high bit rate) needs more seeders to stay on top; releases with no seeder count ("?" in the list) count as 0 seeders and go last. This applies to new "Torrents" configs and to "Reset to the template"; existing configs do not change. The Debrid keys are kept in Melange but not put in the config. On our server `aiostreams.kompotik.com` the server itself searches JacRed; on the other servers AIOStreams searches it through the third-party Magnetio addon (`magnetio.peterdsp.dev`), and with "Torrents" the JacRed address and key are passed to that addon. A server keeps a config for Debrid and one for "Torrents": switching between them does not replace the config, Melange switches to the config of that answer (it is created on the first save with it), and your edits in the AIOStreams web settings stay in both. Debrid needs a key until the server has a Debrid config.
- Release list: a P2P release shows its number of seeders in place of the "?" icon (over 999 as "999+"): dim for 0–2, brighter for 3–9 and 10–29, green for 30 and more; the card on the left shows them too: "P2P · 79 seeders". A Debrid release and a P2P release without a seeder count keep their icon.
- Versions 0.42.2 and older cannot read the settings of the new format: if you go back to an older version, Melange forgets its AIOStreams configs and makes new ones, and the old ones stay on the server.
- English interface: clearer error and hint wording, the settings path now reads Setup → Apps as in the firmware, and an item is consistently called a release.
- Documentation: README in English (README.en.md), CHANGELOG in two languages.

## 0.42.2 — 15.10.2026
- Comet's placeholder no longer plays as a movie. When Debrid refuses (for example, Real-Debrid will not serve a release because of copyright), Comet sends a short clip "Provider is currently unavailable." instead of the movie, and it used to open in the player. ## 0.42.1 — 15.10.2026
- "Download the log": the file now starts with the Dune model and the versions of the firmware and the Dune HD app; after the Melange log comes the tail of the Dune shell log (`shell.log` and the previous `shell.log.old`, up to 1 MB each): it shows why the player or Melange closed in the middle of playback. The shell log hides the serial number, MAC and IP addresses (except `127.0.0.1` and `::1`), names of computers in the home network, and the values of keys, passwords, tokens and cookies; links keep only the server (`http://server:port/…`). Look through the file before sending it: the shell log has the names of your favorites shortcuts, the list of installed plugins and apps, and catalog movie IDs.
- If there is no Melange log (after the Dune reboots), the file still has the Dune details and the shell log.

## 0.39.0 — 09.10.2026
- A Debrid placeholder video no longer spoils the history. Before, a "Cached" release sometimes played a 2-minute or 30-second placeholder (a TorBox limit, an outdated "cached" flag on Real-Debrid, a Torrentio failure), and its progress overwrote the movie position on the "Melange [NN%]" button and in Continue Watching; a placeholder watched to the end marked the movie as watched. Now, before playing via Debrid, Melange asks once for the release link (AIOStreams, Torrentio, MediaFusion, StremThru). If it gets a placeholder instead of the movie, the player does not start, and Melange shows the reason: "Debrid has not downloaded the release yet, try again later", "Debrid limit reached" or "Debrid returned a placeholder video" with the file name. For the next episode in the player, the window "Episode … failed to load" with a "Stop" button appears. The same from Continue Watching.
- If Debrid gave a file link at once, the release plays with history even when it is marked "Not cached" or its status is unknown. The next episodes of such a release also play in a row in the player if Debrid gives links for them too, and Continue Watching opens it via Debrid; if a placeholder comes instead of a link, it goes as before via TorrServer or to the list.
- Comet's placeholder cannot be recognized this way: Comet sends it at once as a video. Nothing changes for TorrServer.
