# Changelog

**English version**

## 0.57.0
- **"Fresh releases" group.** On the settings page, in **Catalog rows**, right after Top, there is a new group of four rows. «Новинки в качестве» and «Новинки в 4K» are movies that recently got a release in good quality or in 4K, from the open list of KinoTrend. «Свежие серии с переводом» are series with a new episode out with Russian translation, from Kinou. «Сезон целиком с переводом» are series that already have a release of a whole season with Russian voice-over, from the open list of SerialTrend. The newest come first. These rows are not among the start rows: tick the ones you want.
- **IMDb rating on the catalog posters.** The posters in the catalog rows show the IMDb rating in the top left corner, so you see it without moving to the tile. Turn it off on the settings page: **Appearance** → **IMDb rating on posters**.

## 0.56.0 — 09.11.2026
- **One row for a release cached in both Real-Debrid and TorBox.** With both keys, a release cached in both services is now one row of the list, with the status "Cached in Real-Debrid and TorBox" (the second service on a line of its own); AIOStreams used to keep the copy of one service only. Releases without an infoHash (MediaFusion) are matched by the file name and size. To get the copies of both services, open the settings page and press **Save** once: Melange updates its AIOStreams config.
- **Main Debrid.** With both keys, the settings page has **Main Debrid: Real-Debrid / TorBox**: a release cached in both plays from the main one. With none chosen, the copy that came first plays, as before. In the release list, MENU → **Main Debrid → TorBox** (or **→ Real-Debrid**) switches it at once; it is there when the list has releases cached in both.
- **Play via the other service.** If Debrid refuses a release cached in both services (an archive, a copyright block, a limit, not downloaded yet, a placeholder), the window now names the service that refused, for example "Real-Debrid could not play the release", and has a **Play via TorBox** (or **Play via Real-Debrid**) button: the same release starts through the other service. The next episodes of this viewing (the playlist of the season, autoplay) go through it too; next time, through the main one again. If the other service refuses too, its reason is shown with no button. Under the player, when the next episode did not load, the same button is there next to **Stop**.
- **A release packed in an archive no longer starts the player for nothing.** Real-Debrid sometimes gives a release as one RAR or ZIP archive instead of the video file; the player could not open it and closed with a general error. Now the player does not start, and Melange shows "Debrid gave an archive, not a video — pick another release". The same for the placeholder Torrentio sends for such a release: it used to show "Debrid returned a placeholder video".
- A Debrid limit placeholder now shows "Debrid limit reached", not "Debrid returned a placeholder video": the AIOStreams file for a TorBox limit and the ElfHosted titles "Debrid limit reached", "Proxy limit reached" and "Too many requests".
- The "Still downloading" and "Still caching" placeholders of ElfHosted addons (for example, MediaFusion with Real-Debrid, AIOStreams) now show "Debrid has not downloaded the release yet, try again later", not "Debrid returned a placeholder video".
- The placeholder of the AIOStreams Debrid when the release has no matching file now shows "Debrid found no matching file in the release — pick another", not "Debrid returned a placeholder video" with the file name.
- The message for other Debrid placeholders now says "Debrid didn't return the video — pick another release" instead of "Debrid returned a placeholder video"; the second line (the file name or the title of the placeholder) is as before.

## 0.55.2 — 09.11.2026

It is checked when all the rows of the group are on, half-checked when some are. The group does not open on a tap on the checkbox, only on its name.

## 0.55.1 — 09.11.2026

If the release does not have the next episode, its list opens to choose another release. After the last episode of the series, the list of the first one opens.
- **The card button opens the list on your release.** The Melange button on the card of a series now opens the list with the cursor on the release you watched, not on the first row: of the same episode, or of the next one if you watched it to the end.

## 0.55.0 — 08.11.2026
- **A clearer info panel in the catalog.** The title above the rows no longer jumps from huge to tiny from one movie to the next: a short title is large, a long one goes in two lines. - Fixed: in search results, "Show all" is now shown only when there are more results than fit in the row; a short list of results no longer has it.

## 0.49.0 — 01.11.2026

The copy and the quality do not change along the way. After **STOP** on another episode than the list, its list opens with the cursor on the same release.
- Fixed: via TorrServer, in a release with seasons in folders, an episode could open from another season. Now, if the folder of the season has this episode, that file opens.

Если вместо фильма заглушка, плеер не запускается, а Melange показывает причину: «Debrid ещё не скачал раздачу, попробуйте позже», «Лимит Debrid» или «Debrid вернул заглушку» с именем файла. У следующей серии в плеере — окно «Серия … не загрузилась» с кнопкой «Стоп». Так же из «Продолжить просмотр».
- Если Debrid сразу отдал ссылку на файл, раздача играет с историей, даже когда она помечена «Нужно скачать» или статус неизвестен. Следующие серии такой раздачи в плеере тоже идут подряд, если Debrid отдаёт ссылку и на них, а «Продолжить просмотр» открывает её через Debrid; если вместо ссылки заглушка — как раньше, через TorrServer или список.
- Заглушку Comet так не распознать: Comet отдаёт её сразу как видео. Через TorrServer ничего не меняется.
