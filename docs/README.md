# Melange: руководство

[← README](../README.md)

Melange превращает Дюну в онлайн-кинотеатр: каталог фильмов и сериалов с подборками и поиском. Выберите фильм, и Melange найдёт раздачи, покажет качество и озвучки и включит фильм в плеере Дюны. Если остановились, продолжите с того же места. Melange встраивается и в «Фильмы» самой Дюны.

Нужна Дюна на Android с прошивкой r24 или r25. Смотреть можно бесплатно через TorrServer или через платный Debrid.

Впервые с Melange? Начните с «Быстрого старта».
