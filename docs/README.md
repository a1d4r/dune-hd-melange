# Melange: руководство

[← README](../README.md)

Melange превращает Дюну в онлайн-кинотеатр: каталог фильмов и сериалов с подборками и поиском. Выберите фильм, и Melange найдёт раздачи, покажет качество и озвучки и включит фильм в плеере Дюны. Если остановились, продолжите с того же места. Фильм можно выбрать и в каталоге «Фильмы» самой Дюны: в карточке, в меню «Смотреть…», есть пункты Melange: карточка и список раздач.

Смотреть можно бесплатно через TorrServer или через платный Debrid.

Впервые с Melange? Начните с «Быстрого старта».
